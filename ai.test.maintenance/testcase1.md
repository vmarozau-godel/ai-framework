# Test Case 1: Main page displays navigation buttons

## Title

The main page should display navigation buttons: Docs, API, Community.

## Steps

1. Open a browser and navigate to `https://playwright.dev/`.
2. Observe the top navigation bar.
3. Verify that a link with the label **Docs** is visible in the navigation.
4. Verify that a link with the label **API** is visible in the navigation.
5. Verify that a link with the label **Community** is visible in the navigation.

## Expected Result

The navigation bar contains visible links for **Docs**, **API**, and **Community**.
